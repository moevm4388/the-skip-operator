# derivative — производная многочлена

## Назначение

Алгоритм вычисляет производную многочлена с рациональными коэффициентами.

За основу взята функция P-12 (derivative) из проекта второго семестра Hestia. Исходный цикл for заменён эквивалентным циклом while.

## Корректная версия (correct.txt)

**Предусловие:** `true`

На вход может поступать любой корректный многочлен, включая константу и нулевой многочлен.

**Инвариант цикла:**

`(i <= d) && (deg(result) <= i) && (forall nat k : (k < i -> coeff(result, k) = (k + 1) * coeff(p, k + 1))) && (forall nat k : (k >= i -> coeff(result, k) = 0))`

Инвариант гарантирует, что:

- счётчик i не превышает степень исходного многочлена;
- степень результирующего многочлена не превышает i;
- все обработанные коэффициенты вычислены правильно;
- все необработанные коэффициенты равны нулю.

**Вариант цикла:** `d - i`

На каждой итерации значение i увеличивается на единицу, поэтому вариант цикла строго уменьшается и остаётся неотрицательным.

**Постусловие:**

`forall nat k : (coeff(result, k) = (k + 1) * coeff(p, k + 1))`

Каждый коэффициент результирующего многочлена соответствует математическому определению производной.

**Ожидаемый вердикт:** Proved.

## Некорректная версия (incorrect.txt)

В некорректной версии при вычислении коэффициента используется множитель i вместо i + 1.

Предусловие, инвариант, вариант и постусловие остаются неизменными.

**Ожидаемый вердикт:** Failed.

### Контрпример

- Исходный многочлен: p = 3x^2 + 2x + 1.
- Ожидаемый результат: 6x + 2.
- Фактический результат ошибочного алгоритма: 3x.

Уже на первой итерации нарушается инвариант цикла: коэффициент при нулевой степени равен 0 вместо 2. Итоговое постусловие также не выполняется.

## Используемые предопределённые функции

- deg(p) — степень многочлена.
- coeff(p, i) — коэффициент при степени i.
- set_coeff(p, i, c) — создание многочлена с изменённым коэффициентом.

## Статус проверки

Вердикты являются ожидаемыми. Фактическая верификация будет выполнена после интеграции с парсером и подсистемой доказательств.
