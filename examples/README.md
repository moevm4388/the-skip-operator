# Библиотека аннотированных программ

## Назначение

Библиотека предназначена для проверки работы верификатора программ на корректных и намеренно некорректных алгоритмах.

За основу взяты алгоритмы системы компьютерной алгебры Hestia, разработанной во втором семестре.

Программы написаны на аннотированном алгоритмическом языке, описанном в ADR 02.

## Ожидаемые контрпримеры

| Алгоритм | Входные данные | Ошибочный результат | Причина |
|---|---|---|---|
| gcd | a = 0, b = 0 | 0 | Нарушение положительности результата |
| derivative | p = 3x^2 + 2x + 1 | 3x | Ошибка вычисления коэффициентов производной |
| simplify | r = 2/4 | 1/4 | Нарушение сохранения значения дроби |

## Используемые аннотации

- input — входные параметры и предусловие;
- output — выходные параметры и постусловие;
- invariant — инвариант цикла;
- variant — вариант цикла;
- forall — квантор всеобщности.

Постусловие gcd записано без кванторов с использованием предопределённой функции gcd.

## Предопределённые функции

- gcd — наибольший общий делитель;
- mod — остаток от деления;
- abs — абсолютное значение;
- div — целочисленное деление;
- num — числитель дроби;
- denom — знаменатель дроби;
- frac — создание рациональной дроби;
- deg — степень многочлена;
- coeff — получение коэффициента многочлена;
- set_coeff — изменение коэффициента многочлена.

Подробное описание алгоритмов и аннотаций содержится в README.md соответствующих каталогов.

## Статус проверки

Для каждой программы определён ожидаемый вердикт в соответствии с эталонными тестами проекта.

Фактическая верификация и проверка совместимости с парсером будут проведены на этапе интеграции.
