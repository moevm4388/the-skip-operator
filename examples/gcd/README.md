# gcd — наибольший общий делитель

## Назначение

Алгоритм вычисляет наибольший общий делитель двух натуральных чисел с помощью алгоритма Евклида.

За основу взята функция N-13 (gcd) из проекта второго семестра Hestia.

## Корректная версия (correct.txt)

**Предусловие:** `a > 0 || b > 0`

Хотя бы одно из входных чисел должно быть положительным. Тип nat гарантирует неотрицательность обоих чисел.

**Инвариант цикла:**

`(x > 0 || y > 0) && gcd(a, b) = gcd(x, y)`

На каждой итерации сохраняется значение наибольшего общего делителя, а текущие числа не равны нулю одновременно.

**Вариант цикла:** `y`

Значение y является неотрицательным целым числом и строго уменьшается при каждой итерации, поскольку mod(x, y) < y при y > 0.

**Постусловие:** `gcd(a, b) = result && result > 0`

Результат равен наибольшему общему делителю исходных чисел и является положительным. Постусловие записано без использования кванторов.

**Ожидаемый вердикт:** Proved.

## Некорректная версия (incorrect.txt)

В некорректной версии ослаблено предусловие: допускаются любые натуральные числа, включая два нуля. Инвариант также адаптирован к изменённому предусловию.

Постусловие остаётся неизменным.

**Ожидаемый вердикт:** Failed.

### Контрпример

- a = 0
- b = 0
- result = 0

Цикл не выполняется, поскольку y = 0. Алгоритм возвращает 0, вследствие чего нарушается постусловие result > 0.

## Используемые предопределённые функции

- gcd(a, b) — наибольший общий делитель.
- mod(a, b) — остаток от деления.

Вердикты являются ожидаемыми. Фактическая верификация будет выполнена после интеграции с парсером и подсистемой доказательств.
