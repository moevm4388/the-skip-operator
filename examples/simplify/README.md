# simplify — сокращение рациональной дроби

## Назначение

Алгоритм приводит рациональную дробь к несократимому виду с сохранением её математического значения.

За основу взята функция Q-1 (reduce_fraction) из проекта второго семестра Hestia.

## Корректная версия (correct.txt)

**Предусловие:** `denom(r) > 0`

Знаменатель исходной дроби должен быть положительным. Это гарантирует, что наибольший общий делитель модуля числителя и знаменателя больше нуля.

Алгоритм вычисляет НОД модуля числителя и знаменателя, после чего делит числитель и знаменатель на полученное значение.

**Постусловие:**

`num(result) * denom(r) = num(r) * denom(result) && gcd(abs(num(result)), denom(result)) = 1 && denom(result) > 0`

Постусловие гарантирует, что:

- математическое значение исходной дроби сохранено;
- результирующая дробь является несократимой;
- знаменатель результирующей дроби положителен.

Инвариант и вариант не используются, поскольку алгоритм не содержит циклов.

**Ожидаемый вердикт:** Proved.

## Некорректная версия (incorrect.txt)

В некорректной версии на НОД делится только числитель, а знаменатель остаётся неизменным.

Предусловие и постусловие остаются без изменений.

**Ожидаемый вердикт:** Failed.

### Контрпример

- Исходная дробь: 2/4.
- Наибольший общий делитель: 2.
- Ожидаемый результат: 1/2.
- Фактический результат ошибочного алгоритма: 1/4.

Нарушается условие сохранения математического значения дроби.

## Используемые предопределённые функции

- num(r) — числитель дроби.
- denom(r) — знаменатель дроби.
- abs(n) — абсолютное значение числа.
- gcd(a, b) — наибольший общий делитель.
- div(a, b) — целочисленное деление.
- frac(n, d) — создание рациональной дроби.

## Статус проверки

Вердикты являются ожидаемыми. Фактическая верификация будет выполнена после интеграции с парсером и подсистемой доказательств.
